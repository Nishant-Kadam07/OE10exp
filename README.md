# Advanced Video Filters and Keyframe Animations in Shotcut

## 1. Project Overview

This project demonstrates video editing techniques using Shotcut, a free and open-source video editor. The project documents the editing workflow and the exported video for Experiment No. 10.

## 2. Tools and Technologies Used

- **Video Editor:** Shotcut
- **Portfolio and Documentation:** GitHub
- **Output Format:** MP4
- **Video File:** `new oe 10.mp4`

## 3. Lab Journey and Implementation

### 3.1 Pre-Production and Asset Gathering

- Selected the video clips required for the experiment.
- Imported the media into Shotcut.
- Arranged the clips on the timeline according to the editing requirements.

### 3.2 Applying Video Filters

- Explored Shotcut's video filter options.
- Adjusted video properties according to the experiment requirements.
- Reviewed the preview to check the visual output.

### 3.3 Keyframe Animation Workflow

- Explored keyframe-based animation in Shotcut.
- Used keyframes where required to animate video properties over time.
- Reviewed the timeline and preview to check the animation.

## 4. Results and Deliverables

- **Video Editor:** Shotcut
- **Export Format:** MP4
- **Exported Video:** [View or download the video](./new%20oe%2010.mp4)
- **Repository:** [OE10exp on GitHub](https://github.com/Nishant-Kadam07/OE10exp)

## 5. Reflections and Key Takeaways

- Learned the basic workflow of video editing using Shotcut.
- Practised importing media, editing on the timeline, and exporting the final video.
- Learned how GitHub can be used to store and document project deliverables.

## 6. Conclusion

This experiment provided practical experience with video editing and exporting using Shotcut. Uploading the final video to GitHub helps preserve the output and makes the project accessible through an online portfolio.
